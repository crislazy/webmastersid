**Live site:** [https://id.webcris.icu](https://id.webcris.icu)

## Run locally

*1.Clone*

```bash
git clone https://github.com/crislazy/webmastersid
cd webmastersid
```

*2.Run*

You can open `index.html` in your browser or run it using:
```bash
npx http-server .
```
